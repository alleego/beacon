# Beacon 0.4.0

- Notes with folders, search, rich text, checklists, pinning and Trash/restore.
- Configurable Enter behavior, with new lines as the default.
- Optional quick start, available again in Settings.
- Local usage history with calendar-month and custom date views.
- Setup guidance and capture previews for compatible optional modules.

Existing chats, settings, credentials and imported modules remain in the same
local profile when upgrading on the same computer and OS account. Quit Beacon
before replacing the app; do not remove its data folder.

Downloads: Intel Mac DMG and Linux x86_64 RPM targeting RHEL 9 desktops.
The Mac build is unsigned and not notarized. The RPM is unsigned; native RHEL 9
runtime validation is pending. Linux requires an unlocked desktop keyring.

Modules are distributed separately and are not included in this release.
Usage recording starts with this version and is not an account-wide billing total.
